# Security Policy

MyOS is experimental operating-system code and is not suitable for production or sensitive workloads.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if enabled. If it is unavailable, contact a repository owner privately through GitHub and include a concise description, affected revision, impact, and safe reproduction details. Do not include secrets or data belonging to others.

There is no guaranteed response time or supported release series yet. Avoid testing against systems you do not own or have explicit permission to assess. Reports should focus on MyOS code and its controlled QEMU test environment.
